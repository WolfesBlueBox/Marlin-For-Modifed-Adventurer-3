
configs for your modified adventurer 3 with BTT SKR 3 v3 mini mainboard.

**These configs are in very much a "Prototype" state and are actively being worked on.**
- This is intended for the Flashforge Adventurer 3 machine, but have / will have only been tested with pro version at this time.
- In addition, **this requires some hardware modification**

short summary:
- update flashforge adventurer 3 to be more open source
- have the expected features of a modern 2025ish machine. (speed, probe, etc)
- using mainboard = Btt Skr 3 v3 mini
- Docs still to be updated.
- configs unfinished. use anything here at your own risk.
- hardware in progress.
- use as many original parts / common spare parts.
- big thankyou to the 3d printing discord and other supporters (you know who you are), as well as the marlin team for making marlin.
- add an easier starting point for people who would like marlin.

**Looking for something more finished?** or something that reuses as much original parts as humanely possble? **Check out the klipperventurer project.**
